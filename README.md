\# ☕ Coffee Shop Sales Data Analytics Dashboard (Excel)



\## 📌 Project Overview



This project is an end-to-end sales analysis dashboard built in \*\*Microsoft Excel\*\* using a real-world coffee shop sales dataset containing \*\*149,000+ transaction records\*\*.



The objective of the project was to transform raw transactional data into an interactive business dashboard that enables users to analyze sales performance, customer purchasing patterns, product performance, and store-level insights.



The dashboard is fully interactive through slicers, allowing users to dynamically explore the data across multiple dimensions. (Except for kpis).



\---



\## 📊 Dataset



\- \*\*Industry:\*\* Retail / Coffee Shop Sales

\- \*\*Records:\*\* 149,000+ transactions

\- \*\*Time Period:\*\* First six months of 2023

\- \*\*Data Type:\*\* Transaction-level sales data



The dataset contains information such as:



\- Transaction Date \& Time

\- Store Location

\- Product Category

\- Product Type

\- Unit Price

\- Quantity Sold

\- (Every other column has been added as per requirements and need from an analytical perspective)



\---



\## 🎯 Project Objectives



The dashboard was created to answer key business questions, including:



\- Which months generated the highest revenue?

\- Which store locations perform the best?

\- Which product categories contribute the most revenue?

\- What are the busiest sales hours?

\- How do weekday and weekend sales compare?

\- Which products generate the highest revenue?
